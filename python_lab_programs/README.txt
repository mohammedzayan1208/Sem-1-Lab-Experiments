# UCEST105 Python Lab Programs

Each Python program is provided as a separate `.py` file. Alternative forms of the same experiment have separate filenames (for example, `exp02_1.py` and `exp02_2.py`).

## Running
Run a file with:
```bash
python exp01.py
```

`exp16.py` requires NumPy:
```bash
python -m pip install numpy
```

Experiment 23 uses two files in the same folder:
- `exp23.py` — main program
- `fibonacci_module.py` — imported module

Keep both files together when running `exp23.py`.

## Notes
The files preserve the programs and approaches shown in the uploaded lab manual, with obvious transcription/formatting errors corrected where needed so the code can run (for example, smart quotation marks, indentation, and the undefined `num` in the iterative factorial example). The manual's Experiment 24/25 descriptions are swapped in places; the filenames follow the experiment headings and actual program code: `exp24.py` is Sticks Game and `exp25.py` is Monty Hall simulation.
